# 🛣️ CrackVision

## 📖 Deskripsi Proyek
CrackVision adalah sistem cerdas yang dikembangkan dalam program Samsung Innovation Campus Batch 6 (Hacktiv) yang didedikasikan untuk keselamatan jalan raya. Perangkat ini menangkap citra visual jalan menggunakan kamera, kemudian memprosesnya untuk mendeteksi kerusakan jalan atau lubang.

Data kerusakan yang terdeteksi dikumpulkan beserta koordinat GPS-nya agar dapat dipetakan secara akurat. Sistem ini berfungsi ganda: memberikan peringatan dini kepada pengendara terkait bahaya di depan, serta menyediakan pemetaan data jalan rusak bagi pemerintah untuk tindak lanjut perbaikan.

**Fitur Utama:**
*   Deteksi jalan rusak dan berlubang menggunakan kamera (*Computer Vision*).
*   Pelacakan koordinat lokasi kerusakan berbasis GPS.
*   Pemetaan dan peringatan lokasi kerusakan.

## 🚀 Teknologi yang Digunakan
*   **Hardware:** ESP32-CAM, Modul GPS.
*   **Software:** C++, Image Processing.

## 📂 Struktur Direktori
*   `/microcontroller` - Berisi *source code* (C++) untuk ESP32-CAM dan integrasi GPS.
*   `/documentation` - Berisi *foto* prototipe fisik.
